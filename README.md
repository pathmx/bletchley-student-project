# My Project

This is your project repo. Everything you build lives here, and your instructors can see your progress through GitHub.

## Quick start

**Option A: Open in Cursor (Mac or Windows)**

1. Go to this repo on GitHub and click the green **Code** button
2. Copy the URL
3. In Cursor, open the terminal (View > Terminal) and run:

```bash
git clone <paste-the-url-here>
```

4. Then open the new folder: File > Open Folder

**Option B: Open in Codespaces (Chromebook or any browser)**

1. Go to this repo on GitHub
2. Click the green **Code** button > **Codespaces** tab > **Create codespace on main**
3. A browser-based editor opens in about 30 seconds

## Your weekly guide

Check `docs/guide.md` for your personalized guide. Your instructors update it each week with goals and next steps tailored to your project and progress.

## Need help? Ask your agent

You can ask the AI agent in Cursor (or Codespaces) for help at any time. Some things to try:

- "What should I work on next?" (it will check your guide)
- "Help me commit and push my changes to GitHub"
- "Explain what this code does"
- "I'm stuck. Here's what I'm trying to do: [describe it]"

The agent knows about your project and your weekly guide. See the [Prompting Cheat Sheet](https://bletchley.path.app/) for more prompts you can use.
